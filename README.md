# TruthLens AI 🔍

TruthLens AI is a mobile-based intelligent system designed to detect whether a given text is written by a human or generated by AI.

## 🚀 Features

- 📱 Mobile app with real-time analysis
- 🧠 NLP-based detection using:
  - Perplexity
  - Burstiness
  - Vocabulary richness
  - Repetition score
- 📊 AI vs Human percentage output
- 💡 Explainable results (why text is AI/human)
- 🔍 OCR-based text extraction from screen

---

## 🧠 How It Works

1. Capture screen content
2. Extract text using OCR
3. Send text to backend
4. Analyze using NLP model
5. Return AI vs Human score
