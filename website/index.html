Explainable Detection Features

We analyze grammatical flow and vocabulary diversity using four core pillars of text metrics.

Perplexity

Measures how predictable words are based on standard language constructs. Lower perplexity suggests machine generation.

Burstiness

Evaluates sentence length and structure variation. Humans write with dynamic variation; AI tends to be uniform.

Vocabulary Richness

Calculates the type-token ratio (TTR) to assess unique vocabulary usage. Reflects the depth of human-made writing.

Repetition Score

Scans for recurring phrases and patterns typical of auto-generated paragraphs to detect automated copy structures.
